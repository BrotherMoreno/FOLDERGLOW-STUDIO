Plantillas

Fondos de pantalla

Los widgets con material “Vidrio” se ven desenfocados sobre el fondo que elijas, como en iPadOS. Para fondos animados (video o HTML) instala Lively Wallpaper desde Complementos; los widgets siguen funcionando encima.

Widgets

Fijos en el escritorio por defecto: quedan debajo de tus apps y no se ocultan con Win + D. Clic derecho sobre un widget para más opciones.

En tu escritorio

Aún no tienes widgets. Añade uno desde la galería.

Aplicaciones

Menú de apps a pantalla completa, como en GNOME: búsqueda, cuadrícula paginada, frecuentes y todas. Incluye apps de escritorio y de Microsoft Store.

Cómo abrirlo

Atajos dentro del menú: escribe para buscar · ← → ↑ ↓ para moverte · Enter abre · Re Pág/Av Pág o la rueda cambian de página · Esc cierra · F5 vuelve a escanear.

Cristal

Motor nativo GlowGlass: 1–2 MB de RAM, 0 % de CPU en reposo, sin Python.

Barra de tareas

En Windows 11 22H2+ la barra dibuja su propio fondo: si no ves cambio, instala TranslucentTB o Windhawk desde Complementos.

Carpetas translúcidas · desenfoque real

No instalado

Tu fondo de pantalla se ve desenfocado detrás de toda la carpeta y el texto queda nítido. Usa ExplorerBlurMica (código abierto, LGPL); FolderGlow lo descarga de GitHub, lo configura y lo registra. Windows pedirá permiso de administrador.

Aplicar y activar reinician el Explorador (la barra de tareas parpadea un segundo); tus carpetas abiertas se vuelven a abrir.

Ajustes

    

      
      
    

    

      
Token de GitHub (opcional)

      
Sin token GitHub permite pocas consultas por hora. Crea un token "fine-grained" sin permisos extra en github.com/settings/tokens.

      

    

    

      
SteamGridDB (opcional)

      
Portadas para juegos que no están en Steam ni traen arte (GOG, Ubisoft, emuladores…). Igual que en Playnite: crea una clave gratis en steamgriddb.com → Preferencias → API.

      

    

    

      
Consumo

      
Motor nativo: ~1–2 MB. Cada widget es una ventana web (~35–50 MB de RAM). Los widgets tapados por otras ventanas se congelan solos. Cierra esta ventana cuando no la uses: la app sigue en la bandeja.
